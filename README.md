One line, one cat, one joke about cats — a setup and a turn that lands. The entry:

> I asked the cat to watch the baby. She moved the baby's blanket, sat on it, and filed for custody.

## Run it

```sh
node main.ts
```

`main.ts` writes the joke to `ENTRY_OUTPUT` or `/output/entry.txt` — a single line, 98 characters, no trailing newline.
